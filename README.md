# Birthday-Card

Welcome to the Birthday Card project! This project lets you create and customize a digital birthday card using HTML, CSS, and JavaScript. You can personalize the card with messages, images, animations, and colors to make it a special gift for a loved one.

# Features ✨
  Personalized messages: You can add a custom birthday message to the card.
  Animations: Includes animated effects like confetti or balloon floats.
  Responsive Design: The card looks great on any device (mobile, tablet, desktop).
Customizable Colors & Images: Choose your background, fonts, and images to fit the birthday theme.
